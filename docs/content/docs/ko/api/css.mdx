---
title: 스타일 API
description: CSS 변수와 CSS Parts
---

| 변수 | 용도 |
| --- | --- |
| `--chrome-tabs-height` | 탭 바 높이 |
| `--chrome-tabs-background` | 탭 바 배경 |
| `--chrome-tabs-font` | 글꼴 |
| `--chrome-tab-min-width` | 탭 최소 너비 |
| `--chrome-tab-max-width` | 탭 최대 너비 |
| `--chrome-tab-radius` | 탭 모서리 반경 |
| `--chrome-tab-text-color` | 기본 텍스트와 아이콘 색상 |
| `--chrome-tab-active-text-color` | 활성 탭 텍스트 색상 |
| `--chrome-tab-hover-background` | 탭 호버 배경 |
| `--chrome-tab-active-background` | 활성 탭 배경 |
| `--chrome-tab-divider-color` | 구분선 색상 |
| `--chrome-tabs-accent-color` | 강조 색상 |
| `--chrome-tabs-menu-background` | 메뉴 배경 |
| `--chrome-tabs-menu-hover-background` | 메뉴 호버 배경 |
| `--chrome-tabs-tooltip-background` | 탭 툴팁 배경 |
| `--chrome-tabs-tooltip-border-color` | 탭 툴팁 테두리 색상 |
| `--chrome-tabs-tooltip-text-color` | 탭 툴팁 텍스트 색상 |
| `--chrome-tabs-tooltip-shadow` | 탭 툴팁 그림자 |

| Part | 요소 |
| --- | --- |
| `strip` | 탭 바 |
| `tab-list` | 탭 목록 |
| `tab` | 탭 |
| `active-tab` | 활성 탭 |
| `title` | 제목 |
| `icon` | 탭 아이콘 |
| `close-button` | 닫기 버튼 |
| `add-button` | 추가 버튼 |
| `group-toggle` | 그룹 열기 버튼 |
| `group-menu` | 그룹 메뉴 |
| `context-menu` | 컨텍스트 메뉴 |
| `tab-popover` | 탭 툴팁 또는 숨겨진 탭 목록 팝오버 |
| `overflow-tab-option` | 숨겨진 탭 목록 항목 |
