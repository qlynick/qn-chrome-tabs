---
title: Styling API
description: CSS variables and CSS Parts
---

| Variable | Purpose |
| --- | --- |
| `--chrome-tabs-height` | Tab bar height |
| `--chrome-tabs-background` | Tab bar background |
| `--chrome-tabs-font` | Font |
| `--chrome-tab-min-width` | Minimum tab width |
| `--chrome-tab-max-width` | Maximum tab width |
| `--chrome-tab-radius` | Tab border radius |
| `--chrome-tab-text-color` | Default text and icon color |
| `--chrome-tab-active-text-color` | Active tab text color |
| `--chrome-tab-hover-background` | Tab hover background |
| `--chrome-tab-active-background` | Active tab background |
| `--chrome-tab-divider-color` | Divider color |
| `--chrome-tabs-accent-color` | Accent color |
| `--chrome-tabs-menu-background` | Menu background |
| `--chrome-tabs-menu-hover-background` | Menu hover background |

| Part | Element |
| --- | --- |
| `strip` | Tab bar |
| `tab-list` | Tab list |
| `tab` | Tab |
| `active-tab` | Active tab |
| `title` | Title |
| `close-button` | Close button |
| `add-button` | Add button |
| `group-toggle` | Group trigger |
| `group-menu` | Group menu |
| `context-menu` | Context menu |
