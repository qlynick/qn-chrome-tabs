---
title: Properties and Types
description: Public component properties and TypeScript data structures
---

| Property | Type | Description |
| --- | --- | --- |
| `tabs` | `ChromeTabItem[]` | Tabs displayed in the current group |
| `activeTabId` | `string` | The active tab |
| `groups` | `ChromeTabGroup[]` | All groups |
| `activeGroupId` | `string` | The active group |
| `locale` | `'zh' \| 'en' \| 'ko'` | Interface language |
| `hideAddButton` | `boolean` | Whether to hide the add-tab button |
| `hideGroupButton` | `boolean` | Whether to hide the group menu trigger |
| `tabTooltipMode` | `'truncated' \| 'always' \| 'never'` | Show tooltips for truncated titles, all tabs, or no tabs |
| `renderTabIcon` | `(tab: ChromeTabItem) => Node \| null` | Custom icon renderer; `null` falls back to `tab.icon` |
| `renderTabTooltip` | `(tab: ChromeTabItem) => Node \| string \| null` | Custom tab tooltip content; return `null` to disable it for that tab |

```ts
tabsElement.renderTabTooltip = (tab) => {
  const content = document.createElement('div');
  content.textContent = tab.title;
  return content;
};
```

```ts
interface ChromeTabItem {
  id: string;
  title: string;
  backgroundColor?: string;
  icon?: ChromeTabIcon;
}

type ChromeTabIcon =
  | { type: 'image'; src: string; alt?: string }
  | { type: 'favicon'; url: string; path?: string; alt?: string };

interface ChromeTabGroup {
  id: string;
  name: string;
}
```
