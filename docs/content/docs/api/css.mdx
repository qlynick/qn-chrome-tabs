---
title: 样式 API
description: CSS 变量和 CSS Parts
---

| 变量 | 作用 |
| --- | --- |
| `--chrome-tabs-height` | 标签栏高度 |
| `--chrome-tabs-background` | 标签栏背景 |
| `--chrome-tabs-font` | 字体 |
| `--chrome-tab-min-width` | 标签最小宽度 |
| `--chrome-tab-max-width` | 标签最大宽度 |
| `--chrome-tab-radius` | 标签圆角 |
| `--chrome-tab-text-color` | 普通文字和图标 |
| `--chrome-tab-active-text-color` | 活动标签文字 |
| `--chrome-tab-hover-background` | 标签悬停背景 |
| `--chrome-tab-active-background` | 活动标签背景 |
| `--chrome-tab-divider-color` | 分隔线 |
| `--chrome-tabs-accent-color` | 强调色 |
| `--chrome-tabs-menu-background` | 菜单背景 |
| `--chrome-tabs-menu-hover-background` | 菜单悬停背景 |

| Part | 对应元素 |
| --- | --- |
| `strip` | 标签栏 |
| `tab-list` | 标签列表 |
| `tab` | 标签 |
| `active-tab` | 活动标签 |
| `title` | 标题 |
| `close-button` | 关闭按钮 |
| `add-button` | 新增按钮 |
| `group-toggle` | 分组入口 |
| `group-menu` | 分组菜单 |
| `context-menu` | 右键菜单 |
