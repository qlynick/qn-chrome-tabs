# Security Policy

**English** | [简体中文](./SECURITY.zh-CN.md)

## Supported versions

Security fixes are applied to the latest published version of
`qn-chrome-tabs`. Please verify the issue against the latest release before
reporting it.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's
[private vulnerability reporting form](https://github.com/qlynick/qn-chrome-tabs/security/advisories/new)
and include:

- The affected version and environment
- A minimal reproduction or proof of concept
- The expected impact
- Any known workaround

The report will remain private while it is reviewed and, when applicable, while
a fix and coordinated disclosure are prepared.

For ordinary defects without a security impact, use the repository's bug report
form instead.
